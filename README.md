# 📊 Learning Probability Density Functions using Non-Linear Transformation & MLE

This project demonstrates how **probability density functions (PDFs)** can be learned from real-world air quality data using a **roll-number–parameterized non-linear transformation** and **Maximum Likelihood Estimation (MLE)**.

The goal is to understand how transformations affect data distributions and how statistical parameters can be estimated from observed samples.

---

## 🔗 Dataset

- **Name:** India Air Quality Dataset  
- **Feature Used:** NO₂ (Nitrogen Dioxide) concentration  
- **Source:** Kaggle  
- **Link:** https://www.kaggle.com/datasets/shrutibhargava94/india-air-quality-data  

---

## 🧠 Objective

The objectives of this project are to:

- Apply a **personalized non-linear transformation** to NO₂ concentration data  
- Model the transformed data using a **Gaussian-type probability density function**  
- Estimate PDF parameters using **Maximum Likelihood Estimation (MLE)**  
- Visualize and analyze the results
